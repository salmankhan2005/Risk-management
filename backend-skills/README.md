# RiskWatch Backend Engineering Skill

A reusable agent skill for building and reviewing the RiskWatch backend.

- `SKILL.md`: main instructions for the coding agent.
- `references/architecture.md`: relationships, migration order, audit, worker semantics.
- `references/risk-rules-and-validation.md`: rules and metrics.
- `references/security-and-api.md`: roles and API conventions.

Install the directory in the skills folder supported by your AI coding environment, then enable/reference the skill. If the environment supports only one file, use `SKILL.md` and keep `references/` alongside it.

This bundle is a specification, not a claim that the backend has already been implemented, deployed, or tested.
